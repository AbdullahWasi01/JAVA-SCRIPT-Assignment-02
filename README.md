# JavaScript Assignment 02

This assignment focuses on practicing basic JavaScript concepts and understanding how JavaScript interacts with users through browser functions.

## Topics Covered

- JavaScript Variables (`var`)
- Increment and Decrement Operators (`++`, `--`)
- User Input using `prompt()`
- Displaying Messages using `alert()`
- Displaying Output using `document.write()`
- Multiplication Tables using User Input
- Marks Calculator with Result Table
- Basic Calculations and Operators

## Features

- Takes input directly from the user.
- Generates multiplication tables based on the entered number (defaults to 5).
- Calculates total marks and percentage.
- Displays results through browser alerts and output tables.

## Technologies Used

- HTML5
- JavaScript

## Purpose

To strengthen my understanding of JavaScript fundamentals and practice writing interactive programs using user input and output.
